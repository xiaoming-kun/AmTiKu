# 题目格式规范

> 公开版。内部规范入口：`设计/题目格式与录题规范-总纲.md`；格式细节真相：`设计/题目规范.md`。

题库是**纯文本 LaTeX**：`题目/001.tex`、`002.tex`…（每卷 ≤5000 题），一题一块。

## 一、一块题长什么样

```latex
%% @q {"key": "示例/demo#1", "type": "single_choice", "answer": "A", ...}
\begin{question}
…题干与选项…
\begin{solution}
…解析…
\end{solution}
\end{question}
```

* `%% @q {…}` 是元数据行（一行 JSON）。**真正被读取的只有 `key`/`type`/`points`/`meta`**；
  `stem`/`options`/`answer`/`solution`/`figures` 是写盘时的渲染副本，读题不看它们
* 题干、选项、答案、解析**都在正文里**——正文才是真相，元数据只是索引
* `key` 由库生成：通常是 `书/出处#N`（如 `高考真题汇编/2024/新高考I卷#1`）；`N` 是入库块序号，**不是原卷题号**

## 二、题型与答案写在哪

| 题型 | `type` | 答案放在 | 卷面上长这样 |
|---|---|---|---|
| 单选 | `single_choice` | `\paren[A]` | 题干末尾的作答括号 |
| 多选 | `multi_choice` | `\paren[ABD]` | 2–4 个字母，无分隔符 |
| 填空 | `fill_in_blank` | `\fillin[$-1$]` | 空位；**段数必须等于空位数**，多空用 `；` 分隔 |
| 解答 | `detailed_answer` | 答案栏写「见解析」 | 解析即答案，题干不留空作答位 |

答案栏（`answer` 字段）与卷面必须一致：改了字段就要改卷面，反之亦然。

## 三、正文的硬性要求（渲染器按这些规则检查）

* 行内公式用 `$…$`，行间用 `\[ … \]`（不用 `$$`），**`$` 必须成对**
* **数学模式里不写中文**（用 `\text{…}` 或挪到公式外）
* 选项用 `\begin{choices}\item …\end{choices}`，**不用** `\begin{enumerate}`
* **解答题题干里的小问用 `\begin{enumerate}\item …\end{enumerate}`，不手写 `(1)(2)`；
  第 2 层小小问也**嵌套** `enumerate`，不手写 `(i)(ii)`／`①②`**
  （上面那条只管选择题的选项，别混：小问走 `enumerate`。前端 `qlatex.ts` 的
  `convertEnumerate` 把它渲染成（1）（2）…，exam-zh 出卷也按同一种编号，
  **只统一一半就会预览≠导出**。
  ⚠️ **只管题干**：`solution` 栏是分段叙述的文字，第 1 层小问仍写行首 `(1)`、`(2)`，
  第 2 层不写编号；解析里不用 `enumerate`（`amti/exchange.py` 里那句「不要用 enumerate」说的就是解析栏）
* 插图：`\includegraphics[width=0.4\linewidth]{<内容寻址名>.png}`，图片放 `图片/`
* **题干里不写「（多选）」这类题型自述**：题型由元数据 `type` 表达，写进题干就是
  同一件事两遍，而且会跟着题干一起印进导出与讲义（存量 333 道已由 `normalize`
  清掉；录入时也会自动删，但**题型还没判准的题不删**——那句是改判的唯一判据）
* 不带分值、页眉页脚（「第 N 页 共 M 页」「绝密★启用前」）
* 解析必须完整：不许半句、半条公式（`\[` 没关、`\frac{` 少花括号都算坏）
* 分数统一 `\dfrac`（新录；存量 `\frac` 不强制迁移）；`\geqslant`/`\leqslant`（不用 `\ge`/`\le`）；平行 `\parallel`（不用 `//`）
* `\left`/`\right` 括号类型要一致（`\left[ … \right]` ✓，`\left[ … \right)` ✗ 会渲染失败）

## 四、完整例子（自编）

```latex
%% @q {"key": "示例/demo#1", "type": "detailed_answer", "answer": "见解析",
%%      "points": ["3.1.1"], "meta": {"book": "示例", "label": "示例卷", "year": 2026}}
\begin{problem}
如图，抛物线 $y=x^{2}-2x-3$ 与 $x$ 轴交于 $A$、$B$ 两点（$A$ 在 $B$ 的左侧），与 $y$ 轴交于点 $C$。

\begin{enumerate}
\item 求 $A$、$B$ 两点的坐标；
\item 求 $\triangle ABC$ 的面积。
\end{enumerate}

\includegraphics[width=0.5\linewidth]{7e044a2c74964f15.png}
\begin{solution}
(1) 令 $y=0$，得 $x^{2}-2x-3=0$，解得 $x=-1$ 或 $x=3$，故 $A(-1,0)$、$B(3,0)$。

(2) 令 $x=0$，得 $y=-3$，故 $C(0,-3)$。于是
\[
S_{\triangle ABC}=\dfrac{1}{2}|AB|\cdot|OC|=\dfrac{1}{2}\times 4\times 3=6 .
\]
\end{solution}
\end{problem}
```

（这道题就在 `demo数据/题目/001.tex` 里，可以直接跑起来看。）

## 五、元数据字段

| 字段 | 说明 |
|---|---|
| `key` | 自然键，全库唯一 |
| `type` | 四种题型之一，见上表 |
| `answer` | 答案串（解答题字段写「见解析」；`.tex` 源文件里不写答案） |
| `meta.book` / `meta.label` | 出处：书/册名与卷名 |
| `meta.year` / `meta.region` | 年份与地区（高考真题用） |
| `points`（顶层） | 考点 id 列表（对应 `知识点.json` 里的 `id`；1–3 个，第一个是主考点） |
| `meta.point_source` | 考点来源：`llm` / `manual` / `库里同题` |
| `meta.difficulty` | 难度：简单题 / 中档题 / 难题（不写则由主考点派生） |
| `meta.difficulty_source` | `human`（人工）/ `model`（模型推定）/ 缺省 = 按主考点派生 |
| `meta.difficulty_conf` | 模型推定的置信度（0–1），只在 `difficulty_source=model` 时有 |
| `meta.answer_source` / `meta.solution_source` | `human` / `workbuddy`（模型）/ `legacy`（历史存量，来源未登记）；模型补的必须标 |
| `meta.reviewed_at` | 人工复核时间（`YYYY-MM-DD HH:MM`）；有值 = 已复核，可筛「已/未复核」 |
| `meta.answer_summary` | 解答题原来的分问答案摘要（答案栏已统一成「见解析」，摘要挪进解析开头） |
| `figures`（顶层） | 该题用到的图片/ TikZ 列表（不是 `meta.figures`） |

## 六、怎么把新题放进去

**不要手工编辑 `题目/*.tex`**（有分卷、规范化、查重、图片入库等一整套流程）。
用程序走：

```bash
python3 amti.py ingest            # 交互式录入（先干跑验证，再落盘）
```

录入时会自动：验证格式（16 项硬检查 + 3 项风格提示，以实际输出为准）→ 规范化 → 查重 → 图片入库 → 追加到主文件。
**没有答案或解析的题会被整批拒绝**——半成品不许入库。

讲义、教案、别的题库那种「标准文件」也能直接喂进来，规范化会把这些写法改成上面的规范形态：

| 你给的 | 入库后 |
|---|---|
| 行内 `\( … \)` | `$ … $` |
| 题干末尾 `（\quad）` + 解析第一行 `答案：C` | 题干 `\paren[C]`，答案进字段，解析里那行删掉 |
| 解析第一行 `【答案】$2$` | 答案进字段，填空位补成 `\fillin[$2$]` |
| 解析开头 `【详解】`／`【解析】` | 栏目名去掉（解析直接从讲解开始） |
| 选项 `\begin{choices}[columns=4]` | 保留选项内容，列数不入库（由导出时按宽度自动排） |
| 没有 `%% @q` 元数据行 | 按 `--book/--label/--year` 生成 |

**修不了的是「猜」**：解析第一行没有答案、答案字母不在选项里、或者两处答案对不上，一律
按缺答案处理、整批拒收——宁可停下问人，也不给错答案。
