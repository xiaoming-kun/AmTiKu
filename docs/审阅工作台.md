# 审阅工作台

> P0 的第一块：让「审阅题库」从一句口号变成一个能算数的流程。
> 入口：左侧「管理 → 审阅」，或总览/体检页的「待审题」。

## 一、先分清两个词

| 词 | 含义 | 谁写 |
|---|---|---|
| **编辑过**（`edited_at`） | 人改过答案、解析、正文或标签 | 各编辑接口 |
| **审阅过**（`review_status` + `reviewed_hash`） | 人看过整道题并做出决定 | 审阅工作台 / 详情页「快速通过」 |

旧实现把两者混在一起：改答案时会顺手写 `reviewed_at`，于是体检页的
「已复核」里绝大多数只是改过一个错字。现在：

* `review_status`：`pending` / `approved` / `needs_fix` / `flagged`；
* `reviewed_hash`：做决定时的 `content_hash`；
* `reviewed_at` / `reviewed_by` / `review_note` / `review_batch`：时间、人、备注、抽样批次；
* **`stale` 不落盘**：正文一变，`content_hash` 与 `reviewed_hash` 对不上，现算成
  「内容已改，原复核失效」。所以改答案、改解析、改源码都不需要记得清复核戳。

旧数据兼容：没有 `review_status` 但有 `reviewed_at` 的，按历史复核处理；
若 `reviewed_at == edited_at`（旧代码改答案时同时写两个字段），算 `stale`。

## 二、风险队列

风险分只用于**排序**，不是对题目正确性的断言。每条命中都带原因，界面上原样显示。

| 信号 | 加分 |
|---|---:|
| 没有答案 / 没有可用解析 | 25 / 25 |
| 题干说「如图」但图没进来 | 20 |
| 录入时标记缺图 | 18 |
| 解析引用了不存在的图 | 18 |
| 答案来源未登记 / 模型生成 / 历史存量 | 16 / 12 / 6 |
| 解析来源未登记 / 模型生成 / 历史存量 | 14 / 10 / 5 |
| 配图分辨率低 | 8 |
| 考点来源未登记 / 模型标注 | 7 / 3 |
| 难度模型置信度 < 0.7 | 4 |
| 有同型题可对照 | 4 |
| 求解时标记存疑 | 12 |
| 内容改过，原复核失效 | 8 |

分档：高 ≥ 35，中 ≥ 18，低 < 18。队列默认按风险倒序，同分按 key。

## 三、分层抽样

* 分层：`book × 题型`；按各层题量比例分配，非空层至少 1 道；
* 只抽 `pending` / `stale` 的题；
* 固定 `seed` 可复现，返回 `batch_id`；
* 复核时带上 `batch_id`，统计页就能按批次算
  「需修改 + 存疑」的占比与 **Wilson 95% 置信区间**。

抽样不是「随机看几道」的仪式：它给的是一个**可复现、可计算误差**的样本。
样本量 100 时，点估计 2%（2/100）的 Wilson 95% CI 约 0.55%–7.0%；想看更窄的区间就加样本。

## 四、接口

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/review/stats` | 状态计数、风险分布、按来源、抽样批次错误率 |
| GET | `/api/review/queue` | 风险队列（`status/risk/book/type/year_from/kw/sort/limit/offset`） |
| POST | `/api/review/sample` | 分层抽样，body：`n/seed/book/type/year_from/risk` |
| POST | `/api/review/decision` | 一批决定，body：`items[{key,status,note}]/reviewer/batch_id` |

写入口只有 `/api/review/decision`（批量一次落盘），详情页的
`PATCH /api/questions/{key} {"reviewed": bool}` 是它的单题快捷方式。
批量改标签里的「快速标记通过」也会写 `approved`，但会留备注
「批量快速通过（未逐题审阅）」——**它不能代替抽样**。

## 五、界面

* 默认**遮住答案**，先自己判，再按 `V` 显示；避免被答案锚定。
* 快捷键：`J/K` 上下、`V` 显示答案、`A` 通过、`F` 需修改、`G` 存疑。
* 右侧显示：审阅进度、风险分布、按来源待审数、抽样批次错误率 + CI。
* 「CSV」导出当前队列/样本（含风险原因、来源、复核人、备注、批次），
  可以离线复核或留档。
* 题目右上角「去题库改源码」：跳到题库详情，并**自动打开源码编辑器**；
  改完保存后回到审阅，原复核会因正文变化自动标成 `stale`。

## 六、验收

```bash
python3 -m amti.review                 # 单元自检：状态、stale、风险、抽样、Wilson
python3 测试/接口测试.py                # 含 queue / sample / decision / stale 用例
python3 amti.py accept                 # 四层全绿
cd web && npx tsc --noEmit --noUnusedLocals --noUnusedParameters && npm run build
```

界面走查：`?view=review`；确认遮罩、通过/需修改/存疑、下一题、统计刷新、CSV 都正常。
