# 缺解析题目 · 外部大模型求解要求

> 规范入口：`设计/题目格式与录题规范-总纲.md`；本文只管“补解析”这条线，产物仍按总纲校验。

> 适用对象：帮助补写解析的外部大模型 / 人工标注员。
> 输入：`数据/题库审阅/缺解析清单_20261017.csv`（或同内容的 JSONL）。
> 输出：按本文格式逐题返回，**不要求改写题库文件**。

---

## 0. 目标

给每道题补一段**完整、简洁、可核验**的高中数学解析，并**核对题库里已有的答案**。

- 题库里 1208 道题缺解析，绝大多数**答案已经有了**；你主要写解析。
- 如果发现答案错了，**不要跟着错答案写**：在 `<核对>` 写 `mismatch`，
  在 `<答案>` 给出你的答案，在 `<备注>` 说明依据。
- 没有把握就写 `unsure`，**宁缺勿错**。空着可以后面补，写错会污染题库。

## 1. 输入格式

每道题至少要有这些字段：

| 字段 | 说明 |
|---|---|
| `key` | 题号，原样带回，**不要改** |
| `type` | `single_choice` / `multi_choice` / `fill_in_blank` / `detailed_answer` |
| `stem` | 题干（LaTeX） |
| `options` | 选择题的选项，`[["A","..."],["B","..."]]`；非选择题为空 |
| `answer` | 题库现有答案；可能为空 |
| `has_figure` | 题干是否依赖配图（`true` / `false`） |
| `points` / `difficulty` | 考点、难度，仅作参考，不要写进解析 |

推荐用 **JSONL**（一行一道题）喂给模型：

```json
{"key":"高考真题汇编/2020/全国III卷（文）#15","type":"fill_in_blank","stem":"设函数 $f(x)=\\frac{\\mathrm{e}^x}{x+a}$，若 $f'(1)=\\frac{\\mathrm{e}}{4}$，则 $a=$\\fillin[1]。","options":[],"answer":"1","has_figure":false}
{"key":"高考真题汇编/2024/新高考I卷#1","type":"single_choice","stem":"已知 $A=\\{x\\mid -\\sqrt[3]{5}<x<\\sqrt[3]{5}\\}$，$B=\\{-3,-1,0,2,3\\}$，则 $A\\cap B=$\\paren[A]","options":[["A","$\\{-1,0\\}$"],["B","$\\{2,3\\}$"],["C","$\\{-3,-1,0\\}$"],["D","$\\{-1,0,2\\}$"]],"answer":"A","has_figure":false}
```

> 注意 JSON 里的反斜杠要写成 `\\`（`\frac` → `"\\frac"`）。
> 如果模型不擅长 JSON，也可以直接把题目按第 2 节的 `@@Q` 块贴进去；**输出统一用 `@@Q` 块**。

本次已经生成好可直接喂的输入：

- `数据/题库审阅/求解输入_20261017.jsonl`：1208 道，一行一题；
- `数据/题库审阅/求解批次/批次_001.jsonl … 批次_061.jsonl`：每批 20 道；
- 其中 **6 道**题干写「如图」但题库没有配图，`has_figure=true`，应返回 `needs_figure`。

## 2. 输出格式（逐题一个块）

```text
@@Q <原样带回的 key>
<状态>ok</状态>
<核对>match</核对>
<答案>-</答案>
<解析>
……解析正文……
</解析>
<备注>-
</备注>
@@END
```

字段说明：

| 标签 | 取值 | 说明 |
|---|---|---|
| `<状态>` | `ok` / `unsure` / `needs_figure` / `error` | `ok` 才代表这段解析可用 |
| `<核对>` | `match` / `mismatch` / `missing` | 你的答案与题库答案是否一致 |
| `<答案>` | 答案文本或 `-` | **只在 `mismatch` 或 `missing` 时填**；否则写 `-` |
| `<解析>` | 解析正文 | `ok` 时必须非空；不要写“解析：”标签 |
| `<备注>` | 一句话或 `-` | 不确定原因、答案冲突依据、题面问题 |

### 状态怎么选

- `ok`：题面完整、你算出的答案与题库一致（或题库本来没答案但你有把握）。
- `unsure`：题面有歧义/条件不足/你算出两个可能结果/没有把握。
  `<解析>` 写 `-`，`<备注>` 说明卡在哪。
- `needs_figure`：题干说“如图”，但你看不到图，且**图是解题必需**。
  `<解析>` 写 `-`，`<备注>` 写“需要配图”。
- `error`：题目明显坏了（缺条件、选项串题、题干截断），无法求解。
  `<解析>` 写 `-`，`<备注>` 指出问题。

> `ok` 的块里**禁止**写 `解析无`、`略`、`同参考答案` 这类占位。

## 3. 逐题型要求

### 3.1 单选题

- 逐个选项判断对错，**不能只写“故选 B”**。
- 最终写“故选 X”。
- 如果题库答案是 `mismatch`，必须说明你的答案为什么对、原答案为什么错。
- 计算型题目要写出关键中间量（判别式、导数、交点、概率分母等）。

### 3.2 多选题

- **每个选项都要单独判断**，明确哪些正确、哪些错误。
- 多选题答案至少 2 个字母；只选 1 个时先怀疑自己。
- 最终写“故选 ABD”这类完整字母。
- 如果某个选项是“以上都对/以上都不对”，要说明它与其他选项的关系。

### 3.3 填空题

- 先推导，再在结尾写“填 …”。
- 多个空按题库答案的顺序，用 `；` 分隔。
- 定义域、值域、端点开闭、是否取等要写清。
- 答案带单位时保留单位；答案不唯一时给出一个并说明“答案不唯一”。

### 3.4 解答题

- 按小问 `(1)`、`(2)`、`(3)` 分段，**每一问都要有完整过程**。
- 证明题：写清方法（综合法/分析法/数学归纳法/反证法/向量法/坐标法），
  关键步骤不能跳；最后写“得证”。
- 求值/求范围：写清定义域、单调性、极值、端点，最后给结论。
- 应用题：设变量、列式、求解、回到实际情境作答。
- 不写评分细则，除非题目明确要求“写出评分标准”。

### 3.5 开放题（“写出一个……”）

- 给出一个满足条件的例子，并**验证它确实满足全部条件**。
- 说明“答案不唯一”。

## 4. LaTeX 与排版规范（必须遵守）

1. 行内公式用 `$…$`，行间公式用 `\[ … \]`。
2. **不要用** `$$…$$`、`//`、`\mbox{}`、`\begin{enumerate}`、`\begin{itemize}`。
   - 平行号写 `\parallel`，不是 `//`；
   - 小问直接写 `(1)`、`(2)`，不要用列表环境；
   - 需要文字盒子时用 `\text{…}`。
3. 中文放在公式外面；公式里必须是 `\text{中文}` 才能写中文。
4. 常用符号：
   - 小于等于 `\leqslant`，大于等于 `\geqslant`（不要用 `\le`/`\ge` 混写）；
   - 属于 `\in`，不属于 `\notin`，包含 `\subseteq`，真包含 `\subsetneqq`；
   - 平行 `\parallel`，垂直 `\perp`，向量 `\overrightarrow{AB}`；
   - 分数 `\dfrac{}{}`（新补解析统一；存量 `\frac` 不强制迁移），根号 `\sqrt{}` / `\sqrt[n]{}`，绝对值 `|x|` 或 `\left|x\right|`。
5. 花括号、`\left…\right` 必须成对；不要写半个命令。
6. 解析正文里**不要**出现 Markdown：不要 `**`、`#`、表格、代码围栏、HTML。
7. 解析正文里**不要**再套 `<解析>` 标签，也不要写“解析：”“答案：”。
8. 长度：一般 80–600 字；压轴题/多问最多 1200 字。**完整但别啰嗦**。

---

## 5. 质量红线与自检

写完每道题，按下面清单自查一遍：

- [ ] 答案代回原式/原条件成立；范围题检查端点。
- [ ] 选择题：每个选项都验证过；答案字母与选项内容一致。
- [ ] 多选题：至少 2 个字母；没有漏选/多选。
- [ ] 填空题：多空顺序与题干一致；开闭区间、单位没丢。
- [ ] 解答题：每一问都有结论；证明题没有跳关键步骤。
- [ ] 没有 `$$`、`//`、`\mbox`、`\begin{enumerate}`。
- [ ] 花括号、`\left/\right` 成对；没有裸中文在公式里。
- [ ] 没有“解析无”“略”“同上”这类占位。
- [ ] 如果题库答案与你的答案不同：**再独立算一遍**；仍不同就 `mismatch`，
      不要为了迎合题库改自己的正确结果。

## 6. 批处理协议

- 每批 **10–20 道**，按题号顺序，**不要漏题、不要合并题**。
- 同一批里每道题输出一个 `@@Q … @@END` 块；块之间空一行。
- 如果某题输出失败（截断/格式坏），也要保留一个 `error` 块并说明原因，
  不要静默跳过——否则后面无法对账。
- 输出被截断时，**整批重跑**，不要把半截解析当结果。
- 建议温度 0.2；`max_tokens` 给足（至少 4000，压轴题给 8000）。
- 返回前自报数量：`本批共 N 题，ok X，unsure Y，needs_figure Z，error W`。

## 7. 示例

### 7.1 单选题（答案一致）

输入：

```text
key: 示例/单选#1
type: single_choice
stem: 已知集合 $A=\{1,2\}$，$B=\{2,3\}$，则 $A\cap B=$\paren[B]
options: A. $\{1\}$  B. $\{2\}$  C. $\{3\}$  D. $\{1,2,3\}$
answer: B
has_figure: false
```

输出：

```text
@@Q 示例/单选#1
<状态>ok</状态>
<核对>match</核对>
<答案>-</答案>
<解析>
由交集定义，同时属于 $A$ 与 $B$ 的元素只有 $2$，所以 $A\cap B=\{2\}$，故选 B。
</解析>
<备注>-
</备注>
@@END
```

### 7.2 填空题（答案一致）

输入：

```text
key: 示例/填空#2
type: fill_in_blank
stem: 已知 $a>0$，且 $a^2=4$，则 $a=$\fillin[2]。
answer: 2
```

输出：

```text
@@Q 示例/填空#2
<状态>ok</状态>
<核对>match</核对>
<答案>-</答案>
<解析>
由 $a>0$ 且 $a^2=4$，得 $a=2$（负根 $-2$ 舍去），故填 $2$。
</解析>
<备注>-
</备注>
@@END
```

> 如果题库答案是 `-2`，则 `<核对>mismatch</核对>`、`<答案>2</答案>`，
> 备注写“$a>0$ 排除负根”。

### 7.3 需要配图

输入：

```text
key: 示例/几何#3
type: detailed_answer
stem: 如图，在正方体 $ABCD-A_1B_1C_1D_1$ 中，$E$ 为 $AA_1$ 的中点，求二面角 $E-BD-A$ 的大小。
answer: 见解析
has_figure: true
```

输出：

```text
@@Q 示例/几何#3
<状态>needs_figure</状态>
<核对>missing</核对>
<答案>-</答案>
<解析>-
</解析>
<备注>题干依赖配图，当前看不到图，无法确定点的位置关系；请补图后再解。
</备注>
@@END
```

### 7.4 多选（答案不一致）

```text
@@Q 示例/多选#4
<状态>ok</状态>
<核对>mismatch</核对>
<答案>ABD</答案>
<解析>
A 项：……，正确；
B 项：……，正确；
C 项：……，错误（反例：……）；
D 项：……，正确。
故选 ABD。
</解析>
<备注>题库原答案 AC 漏了 D；D 项代入 $n=2$ 可验证成立。
</备注>
@@END
```

## 8. 验收口径（给跑批的人）

一批结果收回来后，先做机器检查：

1. 块数 = 输入题数；`key` 全部原样出现、无重复、无遗漏。
2. `ok` 块必须：`<解析>` 非空、不含“解析无/略/同上”、不含 `$$`、`//`、`\mbox`、
   `\begin{enumerate}`；花括号与 `\left/\right` 成对。
3. `mismatch` 块必须有 `<答案>` 和 `<备注>`，人工复核后再决定改不改题库。
4. `unsure` / `needs_figure` / `error` 不计入完成数，单独列出来。
5. 抽 10% 人工复算；重点抽压轴题、多选、答案不一致的。

```text
- 写完代回原式/原条件自检；范围题检查端点；选择题检查每个选项。
- 每批结束自报：本批共 N 题，ok X，unsure Y，needs_figure Z，error W。
```
