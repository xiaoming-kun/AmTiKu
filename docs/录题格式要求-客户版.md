# 录题格式要求（客户版）

> 把题目按下面的格式粘进「录入题目」的输入框，点 **解析成题**。
> 一次可以粘一整份试卷，系统会自动切题；**只粘 LaTeX，不要加 Markdown 代码围栏**。
> 下面是最小够用版；照着四种题型抄，基本不会被拦。

---

## 一、四种题型（照这个写）

> 例子里的 `……` 只是省略；实际粘入时解析要写完整，不能留 `……`／`解析无`／`略`。

### 1. 单选 / 多选

```latex
\begin{question}
已知集合 $A=\{x\mid x^{2}<4\}$，则 $A\cap\mathbb{Z}=$ \paren[B]
\begin{choices}
  \item $\varnothing$
  \item $\{-1,1\}$
  \item $\{-2,-1,1\}$
  \item $\{-2,-1,0,1,2\}$
\end{choices}
\begin{solution}
解 $x^{2}<4$ 得 $-2<x<2$，故 $A\cap\mathbb{Z}=\{-1,0,1\}$。故选 B。
\end{solution}
\end{question}
```

- 答案写在 `\paren[字母]`：单选一个字母，多选按字母序、不加分隔（`\paren[ABD]`）。
- 选项用 `choices`，**2–6 个，原卷几个就几个**；`\item` 里不要写 `A.`。
- 多选的答案不能只写在解析里，必须写进 `\paren[...]`。

### 2. 填空

```latex
\begin{question}
若 $|\vec a|=|\vec b|$，则 $\vec e_1,\vec e_2$ 的夹角为 \fillin[$\dfrac{\pi}{2}$]。
\begin{solution}
由 $|\vec a|=|\vec b|$ 得……故夹角为 $\dfrac{\pi}{2}$。
\end{solution}
\end{question}
```

- 空位只写 `\fillin[答案]`；**不要用 `____`、`______`、`\underline{\hspace{…}}`**。
- 空位要在 `$…$` 外面：`$\theta=$ \fillin[…]` ✓；`$\theta=\fillin[…] $` ✗。
- 多空题：一个空一个 `\fillin`；答案用 `；` 分段。

### 3. 解答题

```latex
\begin{problem}
已知 $\triangle ABC$ 的内角 $A,B,C$ 的对边分别为 $a,b,c$，且
$2\sin A\sin B\sin C=\sin^{2}A+\sin^{2}B-\sin^{2}C$。
\begin{enumerate}
  \item 求 $C$；
  \item 若 $c=\sqrt{2}$，求 $ab$ 的最大值。
\end{enumerate}
\begin{solution}
(1) 由正弦定理得……所以 $C=\dfrac{\pi}{4}$。

(2) 由 $c=\sqrt{2}$ 得……故 $ab$ 的最大值为 $2+\sqrt{2}$。
\end{solution}
\end{problem}
```

- 解答题必须用 `problem`，不能用 `question`。
- 题干的小问用 `enumerate`；**小小问用嵌套 `enumerate`**，不要手写 `(i)(ii)`／`①②`。
- 解析里的小问写行首 `(1)`、`(2)`；第二层不写编号，用空行分段。
- 解答题的答案不用写，系统会自动补「见解析」。

**小小问（第 2 层）这样写**：

```latex
\begin{problem}
……
\begin{enumerate}
  \item 求椭圆 $C$ 的方程；
  \item 过点 $P$ 作两条切线，切点为 $A,B$。
  \begin{enumerate}
    \item 证明：$PA\perp PB$；
    \item 求四边形 $PAOB$ 面积的取值范围。
  \end{enumerate}
\end{enumerate}
\begin{solution}
(1) ……

(2) ……
\end{solution}
\end{problem}
```

## 二、五条硬规则

1. **一题一块**：`question` 或 `problem`，一块一道题；不要两道题挤在一个块里。
2. **答案不能空、解析不能空**：缺答案/缺解析的题会被拦；先补再粘。
3. **解析放在题目环境里面**：`\begin{solution}` 必须在 `\begin{question}`/`\begin{problem}` 内。
4. **公式用 `$…$`**：行间用 `\[…\]`；不要用 `\(…\)`、`$$…$$`。
5. **不要写**：页眉页脚、题号、分值、栏目名（`【解析】` 等）、广告、水印、注释、Markdown。

常用写法：

| 要写 | 不要写 |
|---|---|
| `\geqslant` / `\leqslant` | `\ge` / `\le` |
| `\parallel` | `//` |
| `\dfrac{1}{2}`（新录） | `\frac{1}{2}`（旧格式可读，新录请统一） |
| `\mathrm{i}` / `\mathrm{e}` | `i` / `e` |
| `\mid` | 裸竖线 |
| `$x^{2}$` | `\(x^{2}\)` |

## 三、最常见的 8 种打回

| 现象 | 怎么改 |
|---|---|
| 填空用了 `____` / `\underline{\hspace}` | 改成 `\fillin[答案]` |
| 选择题答案没写进 `\paren[...]` | 把字母写进 `\paren[字母]` |
| 解答题用了 `question` | 改成 `problem` |
| `\begin{solution}` 放在题目环境外面 | 移到 `\end{question}`/`\end{problem}` 之前 |
| 选项里写了 `A.` | 删掉 `A.`，标号由 `\item` 自动生成 |
| `\ge` / `//` | 改 `\geqslant` / `\parallel` |
| 题干里写了题号/分值/页眉 | 删掉；题号只用于你自己核对 |
| 解析只有「解析无」「略」「见解析」 | 补真实解析；补不出先别录 |

## 四、图片怎么处理

- 有图片文件：把图片放进「图片来源目录」，题里写
  `\includegraphics[width=0.4\linewidth]{文件名.png}`，**只写文件名、不写路径**。
- 没有图片文件：**这道题先别录**；不要写假文件名，也不要用文字描述代替图。
- 四个选项各是一幅图：每个 `\item` 放一张图，**不要拼成一张**。
- 表格用 `\begin{tabular}`，不要用 `\multirow`。

---

## 五、出处、年份、地区

- 页面顶部的「来源 / 出处 / 地区 / 年份」可以直接填。
- 也可以在 LaTeX 最上面写一行 `\title{卷名}`，系统会尝试自动填「出处」；不写不影响解析。
- **不要把页眉里的「第 X 页 共 Y 页」「满分 150 分」抄进题目块。**

---

## 六、粘之前自检（10 条）

- [ ] 每道题是 `question` 或 `problem`，一题一块。
- [ ] 选择题有 `choices`，2–6 个选项，选项里没有 `A.`。
- [ ] 选择题答案在 `\paren[...]`；填空答案在 `\fillin[...]`。
- [ ] 填空没有 `____` / `\underline`；空位在 `$…$` 外面。
- [ ] 解答题是 `problem`；题干小问 `enumerate`，小小问**嵌套 `enumerate`**。
- [ ] 每题都有 `\begin{solution}`，且解析不是占位。
- [ ] `$` 成对；没有 `$$`、`\(\)`、`\ge`、`//`。
- [ ] 没有页眉页脚、题号、分值、栏目名、广告、注释。
- [ ] 图片引用的文件真实存在；没有假文件名。
- [ ] 没有 Markdown 代码围栏混进 LaTeX。

## 七、一个可直接粘的小例子（2 题）

```latex
\title{2024年济南市高三模拟考试}

\begin{question}
已知集合 $A=\{x\mid x^{2}<4\}$，则 $A\cap\mathbb{Z}=$ \paren[B]
\begin{choices}
  \item $\varnothing$
  \item $\{-1,0,1\}$
  \item $\{-2,-1,1\}$
  \item $\{-2,-1,0,1,2\}$
\end{choices}
\begin{solution}
解 $x^{2}<4$ 得 $-2<x<2$，故 $A\cap\mathbb{Z}=\{-1,0,1\}$。故选 B。
\end{solution}
\end{question}

\begin{question}
已知 $\sin\alpha=\dfrac{3}{5}$，且 $\alpha\in\left(\dfrac{\pi}{2},\pi\right)$，则 $\cos\alpha=$ \fillin[$-\dfrac{4}{5}$]。
\begin{solution}
由 $\alpha\in\left(\dfrac{\pi}{2},\pi\right)$ 得 $\cos\alpha<0$，故 $\cos\alpha=-\sqrt{1-\sin^{2}\alpha}=-\dfrac{4}{5}$。
\end{solution}
\end{question}

```

> 小小问的嵌套写法见 §3 的模板；真实题目按原卷小问来，不要硬加。
