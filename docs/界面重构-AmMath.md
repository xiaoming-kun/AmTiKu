# AmMath 界面与操作逻辑重构

> 目标：把「能用的功能堆叠」改成「一间清楚的数字教研室」。
> 本文记录这次重构的判断依据、调研对象和落地结果，便于后续继续改时不再走回头路。

## 一、旧界面的问题

不是某一种颜色不好看，而是四个结构性问题叠在一起：

1. **导航平铺**：总览、图谱、讲义、题库、录题、组卷、试卷库、体检、审阅、回收站、变更记录
   11 项同权重。老师每天只用其中两三个，却每次都要在一列里重新找。
2. **首页重复统计**：同一批数字在横幅、4 张 KPI、3 张学段卡、流水线、质量卡里出现四五次；
   真正要做的「继续卷子 / 去挑题」反而被压在下面。
3. **三栏过挤**：侧栏 248 + 列表 520 + 详情 620，1440 宽下几乎贴着屏幕边缘；
   详情里的操作胶囊一多就换行，列表工具栏也排成一长串。
4. **装饰抢焦点**：极光背景、知识星云、渐变标题、玻璃卡片、发光按钮同时出现，
   每一块都在说「看我」，题目反而不是主角。

## 二、GitHub 同类项目调研

调研不是找一张图照抄，而是找这些产品**怎样组织老师的一天**：

| 项目 | 看到的做法 | 对 AmMath 的启发 |
|---|---|---|
| [JudgePeach/math-question-bank (MathBank)](https://github.com/JudgePeach/math-question-bank) | 侧栏只有工作台 / 题库管理 / 导入中心 / 智能组卷 / 试卷记录；首页是 4 个数字 + 最近试卷 + 快速开始；题库是列表 + 详情两栏 | **导航按任务收口**；首页给「继续编辑」，不摆装饰；列表与详情同屏，编辑动作贴着内容 |
| [wnsnnnmwlls/math_warehouse (数研组卷)](https://github.com/wnsnnnmwlls/math_warehouse) | 左侧是题库、标签、AI、考试、函数、试卷合成；题目勾选进入底部「组卷篮」，数量和分值实时变化 | **卷子是一个持续存在的对象**，不是导出的最后一步；底部/顶栏始终能看到「已选多少」 |
| [sophikos/free-math-sheets](https://github.com/sophikos/free-math-sheets) | 一屏分两栏：左边设置，右边即时 PDF 预览；只有一个主按钮 Generate Worksheet | **输出型工作台只有一个主行动**；设置与结果同屏，别让人来回跳 |
| [somethingpluto/exam-system](https://github.com/somethingpluto/exam-system) | 教师端与学生端分开；教师侧是考试管理、分析、试题编辑 | **按角色/任务分工作区**；管理面不该和日常找题混在一列 |

共同点，不是配色，而是：

- 一级导航很少，且以「老师要完成的事」命名，不以数据库表命名；
- 一个屏幕只回答一个问题：找题、组卷、录题、看进度；
- 卷子/篮子这类跨页对象始终可见；
- 管理面（导入、审阅、记录）有位置，但不和主工作流争抢。

## 三、新的信息架构

```
工作台
题库
组卷
内容 ─ 知识图谱 / 讲义
录入
质量 ─ 题库体检 / 审阅
档案 ─ 试卷库 / 回收站 / 变更记录
```

七项一级导航，分成「日常工作」和「资料与质量」两组。组内页面用顶栏下方的二级标签切换，
不再增加侧栏行数。原来 11 项里被收进去的 4 项（试卷库、体检、审阅、回收站/变更）都还在，
只是从「并列的目的地」变成「同一类工作的不同视角」。

## 四、操作逻辑的改动

1. **默认动作从「录题」改成「组卷」**：录题是低频入口，组卷才是题库的出口。
   顶栏只在整个工作流已经有卷子时出现「继续组卷 N」，没有卷子时不放一个会通向空页面的主按钮。
2. **加入卷子不跳页**：卡片上的按钮改为安静的描边按钮，点击后只更新当前卷子并给撤销提示；
   顶栏/侧栏的卷子计数同步出现。找题的节奏不被打断。
3. **首页任务化**：当前卷子 → 接下来 → 最近试卷 → 常用入口 / 覆盖 / 质量 → 学段概况。
   统计数据只出现一次；学段对比用一张表，不再用三张互抢焦点的大卡。
4. **页面标题只出现一次**：顶栏负责「我在哪」，页面内不再放第二层大标题和渐变标语；
   页面开头直接进入工具、统计或列表。
5. **同一类操作收成一组**：详情里的「改源码 / 相似题 / 查重」三个动作归到状态行右侧，
   不再和题型、类别、完整度混成一条长胶囊。
6. **保留键盘工作流**：`⌘K`、`/`、`↑↓`、`Enter`、空格、`⌘↵`、`Z` 都保留；
   `?` 帮助改成居中模态，顶部和命令面板都能打开，右下角不再常驻浮球。
7. **学段切换不丢上下文**：切换小学/初中/高中后，留在当前工作区；
   再点一次已激活的工作区不会跳到别的子页面。

## 五、视觉方向

第一版尝试过「纸色 + 墨色 + 宋体」的教研室风格，实际使用后确认过于克制、和原界面差距太大。
现在回到用户更熟悉的 BoardUI 浅色语言，同时保留新的页面组织：

- **蓝白卡片**：`#f5f5f7` 画布、纯白内容卡，20px 卡片圆角、12px 按钮圆角；
- **学院蓝**：`#0071e3` 作为选中、链接和主操作；紫/青/粉只做少量状态与数字点缀；
- **柔和层次**：卡片一层浅阴影，框架层用轻玻璃；不在题干和选项上做磨砂；
- **无衬线标题**：页面标题、数字、正文保持系统无衬线；不使用宋体作为界面字体；
- **动效只做反馈**：悬停、按下、抽屉进出、数字变化；不做随滚动出现的卡片和常驻光斑。

## 六、录入独立页

点击侧栏「录入」不再替换当前页面，而是用 `window.open` 打开同源的
`?view=ingest`；原标签页的筛选、当前卷子、详情抽屉都保持原样。录入页没有
工作台侧栏、全局搜索栏、当前卷子卡或外观设置，只保留一条 AmMath 录入页头。录入页本身：

- 顶部是「来源 → 核对 → 入库」三步，右上角实时显示当前勾选量；
- 左栏先给源材料，再填出处/年份，最后才是可选批量；不会一进来就面对一堆输入框；
- 右栏在解析前是流程说明，解析后是六项检查：切题、规范、查重、图片、答案解析、入库；
- 有硬伤/疑似重复/缺考点会分别在检查条和逐题明细里显示，不把「可以入库」说成「全部通过」；
- 窄屏用底部「来源 / 核对」切换，不把两栏硬挤在 390px 里；
- 入库完成后通过 `localStorage` 广播一次，原标签页收到后刷新统计。

AI 读取的单独流程（重要）：

1. **先连接**：显示 DeepSeek 连接状态；未配置时先填 Key / 测试，不再先选文件再报错。
2. **再配对**：试题（必选）和答案/解析（可选）分开暂存；换试题会自动清掉上一份答案，避免按题号抄错。
3. **明确开始**：选择文件不再自动上传、不再自动计费；只有点「确认开始读取」才发请求。
4. **读取中**：显示上传/转录/核对阶段、已读页数、耗时，可取消；取消后保留已读部分。
5. **完成后**：先给读取报告（页数、通过核对、待补、答案册覆盖、费用、裁图/警告），
   再让题卡进入右侧六项检查；不会把“读完了”直接说成“全部可入库”。
6. **原文对照**：读取完成后，页面左侧固定一列「原文对照」，可切换试题页/答案页、
   逐页翻看大图，和右侧题卡并排核对；窄屏仍用题卡上的「看原页」弹层。
7. **补解析是显式选项**：只有勾选「缺解析的题让 DeepSeek 补写解析」才会追加请求；
   生成内容标为「解析补写 · 需核对」，在绿条、题卡和报告里都不会冒充原卷解析。

### DeepSeek 整理题库（第三种模式）

和录入并列的第三个入口：**只处理已在库里的题**，不产生新题、不改题干。

1. 选择范围：缺考点 / 缺解析 / 缺答案；
2. 只查本地缺口索引，扫描当前学段最多 10 道；DeepSeek 不会看到整库，可逐题取消勾选；
3. DeepSeek 只返回建议（考点、难度、答案、解析），不写库；
4. 建议按字段勾选后，走现有的 `PATCH`（考点/难度）和 `/solution`（答案/解析）接口写回；
   解析来源记为 `deepseek`，并提示需要重新审阅；
5. 不覆盖已有字段，不做批量静默迁移。

### 题目校对（第四种模式）

- 从题库搜索/选择**一道**已有题，不扫描整库；
- DeepSeek 独立做题，输出答案是否一致、解析问题、配图问题与可选 TikZ；
- 答案/解析逐项勾选后走现有单题接口；TikZ 只给建议，在「改源码 / 补 TikZ」里人工确认保存；
- 读取报告里的 AI 花费用红色大号显示，选文件本身不计费。

## 七、验证

- `cd web && npx tsc --noEmit --noUnusedLocals --noUnusedParameters`
- `cd web && npm run build`
- 浏览器实测：1440 / 1280 / 1024 / 768 / 390 / 320 无横向溢出；
  顶栏、侧栏、二级标签、搜索、帮助、明暗、加入卷子、组卷页面均可用。
- 项目验收：`python3 amti.py accept`、`python3 测试/接口测试.py`（见仓库根 AGENTS.md）。

## 八、边界

- 这次没有改数据层、接口、LaTeX 解析和导出路径；`题目/*.tex` 仍是唯一真相。
- 组卷页仍以「结构 + 检查」为主，没有做 HTML 仿真试卷预览——PDF 版式以 exam-zh 为准，
  再造一套预览会违反「预览与导出一致」的硬约定。
- 产品名改为 AmMath，但安装包、仓库和 `~/Library/Application Support/AmTiKu/` 等历史标识保留，
  避免升级时搬数据。
