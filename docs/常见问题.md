# 常见问题

## 题库数据在哪？能给我一份吗？

本仓库**只有代码**，附 4 道自编 demo 题与完整考点大纲。
真实题库（2 万+ 道，答案 100%、解析 99.9%）是作者的商业数据，**不公开、也不随代码授权**。
需要购买或授权使用，**加 QQ：3138046922** 联系作者。

## 怎么换成自己的题库？

把三样东西放到与代码同级的目录即可：

```
题目/001.tex …      题库主文件（每卷 ≤5000 题，格式见 README「题目长什么样」）
图片/               配图（内容寻址命名，程序自动生成）
知识点.json         考点大纲（可沿用仓库里这份 152 考点的）
```

放好后执行一次 `python3 amti.py snapshot` 建基线，再启动即可。

## 导出 PDF 报「找不到 xelatex」？

「导出试卷 / 讲义 PDF」需要一个 LaTeX 引擎，本仓库不内置（各平台二进制不同）。
按 [TeXLive安装.md](../TeXLive安装.md) 装一次即可，含国内镜像与常见报错处理。
**不装也不影响**浏览、搜索、编辑、组卷与预览。

## 端口被占用 / 想换端口

默认 `8899`（录题台 `8901`）。启动时指定即可：

```bash
python3 -m amti.web.server --port 9001
```

## 服务会自己退出？

是的，**设计如此**：浏览器页面关掉约 25 秒后服务自动退出，不留后台进程。
想常驻就用 `nohup python3 -m amti.web.server &`。

## 我的题库会不会被上传？

不会。全部数据都在项目目录内，程序只监听 `127.0.0.1`，不联任何外部服务
（唯一的联网行为是你自己执行 `pip install` 装依赖）。
