# AI 录题：把一份资料变成题库里的题

> 适合**完全不懂 AI** 的人。照着做，不需要懂什么叫 API、token、提示词。
>
> 原理一句话：把试题/答案页图和《试卷扫描标准化规范》一起交给 DeepSeek，
> 模型直接输出规范 `.tex`、参数、考点和报告；本地只做 preview/规范检查，确认后才进题卡。
> 它只抄不解，不会自己编答案；**不依赖本地大模型**。

---

## 一、第一次用：准备三样东西（约 10 分钟）

### 1. 注册并充值

1. 用浏览器打开 **platform.deepseek.com**，手机号登录；
2. 左边点「充值」，充 **10 元**（够读上千页，后面会算给你看）。

### 2. 创建一把「钥匙」（API Key）

1. 登录后左边点「**API keys**」；
2. 点「**创建 API key**」，随便起个名字（比如 `AmTiKu`）；
3. 屏幕上出现一串 **`sk-` 开头**的字符，点复制。

> ⚠️ 这串东西等于密码：**只显示一次**，别发到群里、别截图发人。
> 丢了就重新建一个，旧的删掉即可。

### 3. 填进软件（只需一次）

1. 打开 AmMath，点左侧导航的「**录入**」，在两种模式里点「**DeepSeek 录题**」；
2. 页面会先显示 DeepSeek 连接状态；第一次用先填一次 API Key；
3. 把 `sk-` 开头那串**粘贴**进去；
4. 点「**保存并测试**」。看到绿色的 **「连接正常（…，xx 毫秒）」** 就成了。

钥匙只存在你这台电脑的 `数据/AI设置.json` 里，界面上只看得到最后四位。
以后换电脑要重新填一次；不想用了，点旁边的小钥匙按钮 →「清掉 Key」。

## 二、开始读资料

### Word 文件：先另存成 PDF

在 Word 里点「**文件 → 另存为**」，格式选 **PDF**，保存。
（软件的 Word 读取会丢公式，所以先转 PDF 最稳。）

### 读

1. 选试题 PDF / 图片 **和可选的答案册**；试题、答案都可以多选，按选择顺序合并；
   选文件只是暂存，不会自动上传；
2. 确认复选框（缺解析是否让 DeepSeek 补写），再点「**确认开始读取**」；
3. 会看到进度：**「已转录 3 / 12 页」** → **「正在核对答案（第 1 / 4 批）」**；
   完成后报告里的实际花费用红色大字显示；
4. **别关窗口**，规范调用完成后自动 preview，右边出现题卡；
   左侧保留「原文对照」列（试题页 / 答案页），可以逐页和题卡对照；
5. 想换一份资料：重新选择试题。换试题会清掉上一份答案，避免按题号抄错；
6. 读取报告里的「查看题卡 / 看识别源码」可以回到核对。

几页的卷子通常 1 分钟内出结果；单次最多 20 页（试题 + 答案合计），超过要拆成几份、每份带上对应的试题页和答案页分别读。

---

## 三、核对（这一步别省）

题卡是先转录、再用答案册原页核对过的；每张卡顶上有 **「答案已复核」**，
可以点 **「看原页」/「看答案页」** 对照，答案/解析下方还有 **原文引用**。
请对着原卷看这四个地方：

| 看什么 | 怎么看 |
|---|---|
| **题干/公式** | 分数、根号、上下标对不对（AI 最容易在这里出错） |
| **选项** | 四个选项齐不齐、有没有串行 |
| **答案** | 是不是原卷的答案；卡上写着「答案：答案册原文」和原文引用，点「看答案页」能对原图 |
| **图** | 卡片下方「待入库图片」里能直接看到裁出来的图 |

三种情况：

- **都对** → 保持勾选，点右下角「**确认入库选中（N 道）**」。
- **有个别错** → 点题卡里的「改源码」就地改，或者先不收这一道（取消勾选）。
- **图上写着「请补图」** → 说明 AI 没画好或没裁好，这道题**先别入库**，取消勾选；
  以后用「录入」自己补一张图。

> **规范检查不通过的题不会进题卡**——缺答案、缺解析、公式/块形不合法、
> 答案册自己标了「错题/条件矛盾」，都会进「未入库」清单并写明第几题、什么原因。
> 这是软件的硬规矩（每道题都得能印出答案，且答案有原文出处）。
> 补好答案后，用「录入」把漏的题补上即可。

## 四、要花多少钱、多久

- 收费只发生在调用 DeepSeek 的步骤：一页图约 **1000 token**；答案册只整份读**一次**，
  一次调用会把题页/答案页一起给模型，成本按页图 + 输出 token 估算；
- 100 页的资料大约 **几毛到 1～2 元**（以 DeepSeek 当前价格为准；控制台能看到余额）；
- **本次实际用量和估算费用会写在结果提示里**（「用量 N tokens，约 ¥x.xx」），
  不再需要自己估；
- 时间：100 页约 15～30 分钟。

## 五、出错了怎么办

| 屏幕上说 | 怎么办 |
|---|---|
| API Key 不对或已失效 | 去 platform.deepseek.com 重新复制一个，填进来 |
| 账户余额不足 | 充值（10 元起步） |
| 请求太频繁被限流 | 等十几秒重试；或在「高级设置」里把并发改成 1 |
| 连不上 DeepSeek | 检查网络/代理；公司网络可能拦了 |
| 一题都没录出来 | 看提示里的「未入库」原因：缺答案/缺解析、答案册标错、核对未过；先补答案再录 |
| 只吃 PDF 和图片 | Word 请先「另存为 PDF」 |
| 图没裁好 / 没画好 | 卡片上会标「请补图」，默认不会勾选；补图后再入库 |
| 有题显示「核对未过」 | 多半是答案册没有这道题/答案没抄到；看「未入库」原因，补答案后用「录入」补录 |
| 答案册自己标了「错题」 | 软件会单独列出来（如「第8题：原题条件矛盾」），不会硬塞一个答案进库 |
| 读太久 / 想停止 | 点进度卡片右边的「取消」；已读到的题会保留，已经发出去的请求仍会计费 |

## 六、三件要提前知道的事

1. **资料会被发送到 DeepSeek 的服务器**（这是它能读懂题的前提）。
   涉密、内部资料不要用这条路。**这条路不依赖本地模型**：没有本地大模型也能用；
   反过来说，涉密资料没有本地替代方案时只能手工录入。
2. **缺答案/解析按批次口径。** 勾选允许补写时，模型才补并写进报告；否则留空进跳过清单。
3. **入库前的那一眼是你的责任。** 软件已经把格式、查重、缺答案、答案原文都挡了一遍，
   但"答案抄错一行"这种事只有人看得出来。

## 七、什么资料效果好

| 好 | 差 |
|---|---|
| 电子版 PDF（Word 导出、排版规整） | 手机斜着拍的、有阴影的 |
| 答案和题目在**同一份**文件里；或题目/答案分两份，选答案文件 | 只有题目、没有答案（会全部进「未入库」） |
| 单栏、字够大 | 双栏密排、小字、扫描歪斜 |
| 有卷头（能认出「2024年XX卷」） | 只有一页照片、没有卷头（出处要自己填） |

## 八、给维护者（可以跳过）

- 入口：左侧导航「**录入**」→ 卡片「**DeepSeek 录题**」——和「手工录题」是同一个独立页的两种模式
  （`IngestWorkspace mode="ai"`），逐题核对/勾选/入库那套代码只有一份。

> 当前 UI：录入在独立标签页打开，没有工作台侧栏；AI 读取先连接 DeepSeek、
> 再配对试题/答案，点「确认开始读取」才上传计费；选文件不会自动开始。
> 缺解析可显式勾选让 DeepSeek 补写；生成解析会标为模型解析，需人工核对。
- 模块：`amti/deepseek.py`（配置 + OpenAI 兼容调用 + usage/费用估算）、
  `amti/ai_spec.py`（规范驱动：页图 → 模型直出规范 `.tex` → 本地 preview）。
- 数据流：
  1. 答案册整份读一次 → `{题号: {answer, solution, page, flawed, note}}`；
  2. 第一遍按页转录题干/选项/图/考点，答案栏只抄题页上直接印的；
  3. 第二遍把「转录 + 题页图 + 答案册原文 + 答案页图」交给核对员，
     返回 `ok / corrected / missing / flawed / uncertain`；**只有 ok/corrected 且答案/解析/引用齐全**才组装；
  4. 题号覆盖：答案册有、第一遍没转录的有效题会定向补读一次（≤12 页时）；
     答案册标错题的进 `pending`，不会静默消失。
- 接口：`/api/ai/status`、`/api/ai/config`、`/api/ai/test`、`/api/ai/run`（异步任务）、`/api/ai/job/{id}`（轮询进度；结果带 `items`/`coverage`/`pending`/`page_dir`/`stats.usage`/`stats.cost_cny`）、`/api/ai/job/{id}/cancel`（取消；已核对过的保留，未核对的进 pending）。
- **写库仍然只走 `ingest`**：AI 只产出源材料文本，解析/规范/查重/缺答案闸门全在 `amti/ingest.py`。
- 图：`crop` 从**同一张页图**上裁（模型给归一化框，本地 Pillow 裁），
  落在 `数据/缓存/AI图/<任务>/`，由 `ingest` 的图片入库搬到 `图片/`；
  `tikz` 走 `amti/tikzfig.py` 编译校验，过不了就在正文里标「请补图」。
- 原页/答案页：渲染出的 `q-*.png` / `a-*.png` 留在同任务 `pages/` 下，
  结果的 `page_dir` + `items[].pages` / `items[].answer_pages` 提供给前端；
  「看原页」走 `/api/ingest/preview-image?path=q-N.png&src_dir=<page_dir>`，只读。
- 逐题元数据：`items[].answer_quote` / `solution_quote` / `verdict` / `verified` /
  `answer_source`（answer_sheet|inline）/ `confidence`；源材料的 `%% @q meta` 里也写
  `verified` 和两份原文引用，入库后还能追溯。
- 费用：`deepseek.chat(..., on_usage=...)` 每次回传 usage，任务内累加；
  `deepseek.cost_cny()` 按 `PRICES` 估算，只作界面提示，以控制台账单为准。
- **不接本地模型/9B 补标**：本流程只走 DeepSeek；考点/难度由第一遍直接给，
  空着就空着，不在录题流程里偷偷加载本地模型。
- 自检：`python3 -m amti.ai_spec --selftest`（**不发网络请求**），`accept` 里有这一项。
