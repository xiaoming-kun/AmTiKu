## 二、这一版修了什么（为什么值得重发）

| 问题 | 原来的后果 | 现在 |
|---|---|---|
| Windows 导出时 `\graphicspath` 被写成 `D:\a\...` | **只要卷子里有配图，导出必定失败** | 已修；在真 Windows 上用包内题真编了一份 PDF 通过 |

## 七、对方可能问的问题

| 问题 | 怎么答 |
|---|---|
| 双击 `启动.bat` 没反应 | Windows 给"从网上下载的文件"打的标记：右键 `启动.bat` → 属性 → 勾「解除锁定」→ 确定（一次即可） |
| exe 版弹"已保护你的电脑" | 更多信息 → 仍要运行（一次即可）；macOS 先 `xattr -dr com.apple.quarantine .`，或系统设置 → 隐私与安全性 → 仍要打开 |
| 导出 PDF 报错 | 报错原文会显示在界面上，也可以看导出目录里的 `.log`；正常情况下不用另装任何东西（LaTeX 已内置） |
| 导出慢 | 第一次导出要初始化字体与格式，约十几秒；之后正常 |
| 想备份 / 换电脑 | 复制「题目」「图片」「知识点.json」三样即可（约 600 MB）；源码版再带上 `归档快照.json` |
| 端口被占用 | 源码版：`python -m amti.web.server --port 9001`；exe 版：`AmTiKu.exe --port 9001`（macOS 用 `./AmTiKu --port 9001`） |
| 能不能放到 U 盘 | 可以，但要整个文件夹一起拷（源码版靠 `tex/` 与 `依赖/`；exe 版还要 `_internal/`，缺一不可） |
| 杀毒软件报警 | 没买数字签名，国产杀软偶尔误报，加白名单即可；程序只监听 127.0.0.1 |
| 有没有手机版 | 没有。它是跑在电脑上的本地程序，手机可以用浏览器访问同局域网里的这台电脑 |
| 数据会不会传出去 | 不会。程序只监听 127.0.0.1，不发任何网络请求 |
