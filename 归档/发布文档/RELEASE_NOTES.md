## 怎么开始（Windows）

1. **先解压**（别在压缩包里直接双击）
2. 双击 **`启动.bat`** —— 只有一个入口：
   * 机器上没有 **Python 3.11+** → 自动装上包里自带的 Python 3.13.15
     （只装给当前用户，**不需要管理员权限、也不需要联网下载**）
   * 依赖全部走包内 wheel，**离线**安装，约 1~2 分钟
   * 然后自动打开浏览器： <http://127.0.0.1:8899>
   * 双击没反应 → 右键 `启动.bat` → 属性 → 勾「解除锁定」（Windows 给下载文件打的标记，一次即可）
3. 以后再开：还是双击 `启动.bat`，环境已就绪，几秒起服务。
   用完关掉浏览器页面，程序 25 秒后自动退出（那个黑窗口就是程序本体）。

**放在哪个目录都行**，含中文、带空格的路径都可以——导出用的 LaTeX 引擎会在
`%TEMP%` 下建一条纯 ASCII 目录联接再启动，绕开 kpathsea 的中文路径限制。

## 里面有什么

| | |
|---|---|
| 后端 | Python 3 + 自研 HTTP 服务（`amti/`，25 个模块），完整源码 |
| 前端 | React + TypeScript **源码 + 已构建产物**（`web/dist/`，所以不用装 Node） |
| LaTeX | **内置 Windows 版最小 TeX Live**（`tex/`，含 exam-zh / elegantnote 等本项目要用的宏包） |
| Python | **内置安装包**（`依赖/python-3.13.15-amd64.exe`），没 Python 时自动装 |
| 依赖 | `依赖/wheels/` 离线 wheel，装依赖不用联网 |
| demo | 出厂 4 道自编题：1 单选 / 1 多选 / 1 填空 / 1 解答（含 1 张抛物线图） |

## 能做什么

* 按章节 / 考点 / 年份 / 难度 / 题型筛题；看题干、选项、答案、解析、考点、出处
* **组卷导出 PDF**：高考卷按真卷结构 8 单选 + 3 多选 + 3 填空 + 5 解答排布，可出留空学生版
* **A4 讲义**（一题一页，题目下方整片留白，给 iPad 讲课用）
* 录入题目：粘贴 LaTeX，入库前自动跑格式检查与查重
* 程序只监听 `127.0.0.1`，不联网、不上传任何数据

## 电脑要求

* Windows 10 / 11 **x64**，**2 GB 内存**、约 2 GB 空闲磁盘（解压后约 1 GB）
* 现代浏览器（Chrome / Edge / Firefox）
* **完全离线可用**——不需要联网、不需要注册、不需要预装任何东西

## 换成自己的题库

把四样放到解压目录下（与代码同级）覆盖同名文件，再跑一次
`python amti.py snapshot` 建基线，重启服务即可：

```
题目/001.tex …      题库主文件（每卷 ≤5000 题，LaTeX）
图片/               配图（内容寻址命名，程序自动生成）
知识点.json         考点大纲
归档快照.json        基线快照
```

格式说明见仓库里的 `AGENTS.md` 与包内 `使用说明（先看我）.txt`。
