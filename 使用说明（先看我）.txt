AmTiKu · 高中数学题库与组卷系统（**含题库**）
==================================================

解压出来是一个文件夹，双击一个 .bat 就能用。**题库已经在里面了。**

一、怎么开始（Windows）
  1. 先解压（别在压缩包里直接双击）
  2. 双击  安装环境.bat   ← **只做这一次**
     · 它先看这台机器有没有 **Python 3.11 / 3.12 / 3.13**：
       没有的话，**自动把包里带的那个 Python 装上**
       （只装给当前用户，不需要管理员权限，也不需要你联网去下载）
     · 然后建运行环境并装依赖：**依赖都在包里，不用联网**，约 1~2 分钟
     · 看到「[OK] 运行环境已就绪」就成了。
     · **已经就绪时它会直接退出，什么都不装** —— 重复双击也没事。
  3. 双击  启动.bat        ← 平时只用这一个
     · 它**只负责启动**：环境的事一律不管，缺了就叫你先去跑 安装环境.bat。
     · 自动打开浏览器： http://127.0.0.1:8899 —— 进去就是完整题库
     · 用完关掉浏览器页面，程序 25 秒后自己退出（那个黑窗口就是程序本体）
     · 如果双击**没反应**，那是 Windows 给"从网上下载的文件"打的标记：
       右键 启动.bat → 属性 → 勾「解除锁定」→ 确定（只需一次）。
       安装环境.bat 同理。

二、这个包里有什么
  · **题库**：高考真题汇编（1991–2026）+ 各地模拟题，**答案 100%、解析 99.9%**
  · **配图**：`图片/` 下按内容寻址命名（改文件名会断引用，别改）
  · **考点大纲**：`知识点.json`（课标体系）
  · **完整源码**：后端 Python（amti/）+ 前端 React 源码（web/src/）
  · **已构建好的前端**（web/dist/）—— 所以你**不用装 Node**
  · **内置 LaTeX 编译器**（tex/）—— 所以你**不用装 TeX Live**，导出 PDF 直接能用
  · **内置 Python 安装包**（依赖/python-3.13.15-amd64.exe）—— 机器上没有 Python 时自动装
  · 离线依赖（依赖/wheels/）—— 装 Python 依赖不用联网

三、能做什么
  · 按章节 / 考点 / 年份 / 难度 / 题型筛题；看题干、选项、答案、解析、考点、出处
  · 组卷导出 PDF（高考卷按真卷结构排布；可出留空的学生版）
  · 录入题目（粘贴 LaTeX，入库前自动跑格式检查与查重）
  · 程序只在本机运行，不联网、不上传任何数据

四、数据说明
  · 题库就是纯文本 LaTeX，在 `题目/`（5 卷）与 `图片/` 里；
    换电脑只要拷 `题目/`、`图片/`、`知识点.json`、`归档快照.json` 四样。
  · `归档快照.json` 是**基线**：`python amti.py diff` 拿它比对，
    用来发现"存量题有没有被误改"。别手改它。
  · **删题要口令**：口令写在 `数据\\删题口令.txt`（一行文本，本包不含，自己建一个）。
    没这个文件时删题会被拒绝 —— 这是有意的（防手滑）。
  · 改库前先 `git status`（如果放进 git 了）；**不要**直接编辑 `题目/*.tex`。

五、常见问题
  · 放在哪个目录都行（含中文、带空格的路径都可以）。
  · 自动装 Python 失败 / 想自己装 → 下载 https://www.python.org/downloads/
    （国内用 https://mirrors.huaweicloud.com/python/ ，快很多），
    **安装时务必勾上 "Add python.exe to PATH"**。
  · 导出 PDF 报错 → 报错原文会显示在界面上，也可以看 试卷\\ 里同名的 .log。
  · 端口被占用 → 命令行执行： python -m amti.web.server --port 9001
  · 想改前端 → cd web && npm install && npm run build（改完**必须**重新构建）
  · 验收 → python amti.py accept（四层全绿，「快照·内容变化」必须是 0）
