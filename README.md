# AmTiKu · 高中数学题库与组卷系统

本地运行的高中数学题库：**检索 → 组卷 → 导出 → 讲义**，全部数据在本机，不上传任何服务器。
后端 Python（自研 HTTP 服务），前端 React + TypeScript，题目用 **LaTeX** 描述、界面用 **KaTeX** 渲染。

* **左栏**是**全局导航**：工作流（工作台 / 题库体检 / 录入 / 知识点）+
  组卷输出（智能组卷 / 试卷管理 / 回收站 / 变更记录），每项都挂一个单键快捷键
* **筛选面板**按**章节 → 节 → 152 个考点**收题，点击即筛；还能按「缺答案 / 缺解析」找活。
  不筛题时可以把它收起来，题目占满全宽
* **列表卡片**自带来源、考点、难度、齐全度，以及**可展开的答案与解析**（不用点进详情就能
  判断这题能不能直接印）；选择题还有选项两列预览
* **批量改标签**：勾 N 道 → 考点/难度/星级/年份/地区/书卷名一次改完，**只写受影响的卷**；
  改完整批过规范审查，有一条不合规就整批不存
* **搜索按相关度**（FTS5 召回 + 题干 > 考点 > 答案 > 解析细排），多词按 AND；
  默认不再按录入顺序返回
* **复核标记**：详情页一键标记「已复核」，可筛「已复核 / 未复核」；人改过答案/解析会自动打戳
* **当前卷子**住在题目栏顶部那一条里（「已选 N 题 · 多少分 · 有解析几道」），点一下就在**同一栏里**
  切成卷子视图——**没有第三个栏目**，所以题目永远占满剩下的宽度
* **题目详情**是按需滑出的抽屉（卡片右上角那个按钮打开，Esc 关掉）：改答案、改解析、改考点、
  **改源码**（整道题的 LaTeX）都在这儿，不看不占地方
* **⌘K 命令面板**：九个入口 + 十几个动作一个框全包，支持拼音（`daochu` → 导出），
  搜不到就直接在题库里搜这个词
* **做错了能退**：加题、移出、清空卷子都会给一条带**撤销**的提示（Gmail 那种），
  所以「清空卷子」不再需要点两下确认
* **组卷**：高考卷（按真卷结构 8+3+3+5 排布）/ 纯测试卷 / 考点覆盖卷 / 讲义，
  留空版可直接给学生作答；**单题换题**只换一道、不打断已排好的顺序；**讲义**为一题一页 A4，可选字号与答案
* **组卷硬约束**：缺图、短解析、逐字重复、同型题族只取一道；同一考点默认最多 2 道；
  可只看近年；卷末可附**答题卡**（选择填涂 + 填空横线；解答题在卷面一页一题、题目下留白）；**细目表导出 CSV**、
  预计用时一并给出；**导出后可看页数/每页空白条/跨页警告**，支持时间预算、地区筛选、三连导出、复制组卷方案
* **题库体检**：覆盖率、难度结构、章节题量、年份/来源、缺解析/无标签来源/考点缺口，点数字直接跳到筛好的题；
  难度分「人工 / 模型推定 / 考点代理」三种口径（模型与人工交叉验证一致率约 74%，见 `变更记录/`）

更多截图与逐页说明见 **[docs/功能介绍.md](docs/功能介绍.md)**，常见问题见 **[docs/常见问题.md](docs/常见问题.md)**。

## 三、快速开始

### 方式一：下载发布包（推荐）

到 [Releases](https://github.com/xiaoming-kun/AmTiKu/releases) 下载，解压后双击
`启动 AmTiKu.command`（macOS）或 `启动.bat`（Windows）——自动建环境、放 demo 数据、
起服务并打开浏览器（关掉页面 30 秒后服务自动退出；想保活用 `AMTI_KEEP_ALIVE=1 ./启动.sh web`）。需要机器上有 **Python 3.11+**。

### 方式二：从源码跑

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp -R demo数据/题目 ./题目 && cp -R demo数据/图片 ./图片 && cp demo数据/知识点.json ./知识点.json
python3 amti.py snapshot          # 建一次基线
./启动.sh 网页                     # 起服务 + 打开浏览器（http://127.0.0.1:8899）
```

## 四、题目长什么样

一道题 = 一个 `question` 环境 + 前面一行元数据（JSON 里只放 LaTeX 表达不了的字段）：

```latex
%% @q {"key": "高考真题汇编/2024/新高考I卷#1", "type": "single_choice", ...}
\begin{question}
已知 $A=\{x\mid -\sqrt[3]{5}<x<\sqrt[3]{5}\}$，$B=\{-3,-1,0,2,3\}$，则 $A\cap B=$\paren[A]
\begin{choices}
  \item $\{-1,0\}$
  \item $\{2,3\}$
  \item $\{-3,-1,0\}$
  \item $\{-1,0,2\}$
\end{choices}
\begin{solution}
因为 $1<\sqrt[3]{5}<2$，所以
\[
-\sqrt[3]{5}<-1<0<\sqrt[3]{5},
\]
而 $-3$、$2$、$3$ 都不在该区间内，故 $A\cap B=\{-1,0\}$。故选 A。
\end{solution}
\end{question}
```

* **答案写在作答位置**：选择 `\paren[A]`、填空 `\fillin[$-1$]`、解答写「见解析」
* **正文是字段的真相**：元数据行只补 LaTeX 表达不了的（key / 来源 / 考点）
* 题库按卷存放：`题目/001.tex`、`002.tex`…（每卷 ≤5000 题）
* **完整格式规范见 [docs/题目格式.md](docs/题目格式.md)**（题型、答案位置、元数据字段、渲染器硬性要求、怎么录入）

## 六、导出 PDF 需要自己装 LaTeX

「导出试卷 / 讲义 PDF」需要一个 LaTeX 引擎（程序调用 `xelatex`）。
本仓库**不内置**（各平台二进制不同，且在别人机器上容易因字体/映射缺失而编译失败）。
按 **`TeXLive安装.md`** 装一次即可（macOS / Windows / Linux 三平台，含国内镜像与常见报错处理）。

**不装也不影响**浏览、搜索、编辑、组卷与预览。
