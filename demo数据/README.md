# demo 数据（20 道示例题）

这 20 道题用来让拿到包的人**能立刻跑通界面、看到真实排版质量**。正式题库不在本仓库、
也不随包发布。

## 这 20 道是怎么来的

从正式题库里挑的**真实题目**（不是自编的空壳），按高考卷面比例取样：

| | |
|---|---|
| 题型 | 9 单选 / 3 多选 / 3 填空 / 5 解答 |
| 难度 | 7 简单 / 9 中档 / 4 难题 |
| 考点 | 20 个**互不相同**的考点（按课标体系） |
| 配图 | 5 道带图（全部是位图，不需要现渲染 TikZ） |

**出处信息已抹掉**：`meta.book` / `source_label` 统一改成「示例卷」，
`region` / `year` / `source_no` 删除，`key` 重编为 `demo/示例卷#1…20`。
题目正文、选项、答案、解析**一个字没改**——它们和正式库里的一模一样。

## 怎么用

把这三样复制到数据目录（它们与代码期望的路径一致）：

```bash
cp -r demo数据/题目   ./题目        # 题库主文件（001.tex）
cp -r demo数据/图片   ./图片        # 配图（内容寻址命名）
cp    demo数据/知识点.json ./知识点.json   # 考点大纲（完整 152 个考点）
python3 amti.py snapshot            # 建一次基线
python3 amti.py 网页                 # 起服务 + 打开浏览器
```

Windows 上用 `xcopy /E /I` 或直接拖文件夹即可。

以 `.app`（macOS）运行时，数据目录是 `~/Library/Application Support/AmTiKu/`，
首次启动会自动把这份 demo 放进去。

## 换成自己的数据

- 题目放在 `题目/001.tex …`（每卷 ≤5000 题，格式见 `设计/题目规范.md`）；
- 图片放 `图片/`，文件名用内容的 sha256 前 16 位（由 `amti/images.py` 自动生成）；
- 数据目录可用环境变量 `AMTIKU_ROOT` 指定。
